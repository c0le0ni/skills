# Glossary

The bakery's words, so that everyone means the same thing.

| Term | Meaning |
| --- | --- |
| Daily | One of the 12 products baked every day |
| Cake order | An order with a pickup date at least 48h ahead |
| Pickup | When and where the customer collects; the shop counter |
| Day board | The counter's list of every order for a day |
| Ready | The order is packed and waiting; the customer gets a message |
| Standing order | A café's weekly wholesale order (out of scope, in the Sheet) |
| Availability | Whether a product can be ordered today |
