# Voice

From the scope and the approved screens.

- Short sentences. Second person to the player: "Follow the green".
- No em dash, no emoji, no hype words.
- Labels in uppercase mono, a few words each: STREAK, PIXELS, RUN OVER.
- English by default, Portuguese when the browser asks for it. Both say the same thing.

| Say | Not |
| --- | --- |
| Follow the green with your mouse. Click to start. | Welcome to Streak! Get ready for the ultimate challenge |
| Run over | Game over! Better luck next time |
| You can buy 4 upgrades | Unlock amazing power-ups now |
