# Design system

Source: brand notes and the photographer's mood board (`../../input/brand-notes.md`).
Values marked *to confirm* came from photos, not from a file.

## Colors

| Token | Value | Use |
| --- | --- | --- |
| `--bg` | `#F6F0E6` | Page background, the cream of the paper bags |
| `--surface` | `#FFFDF8` | Cards and the counter board rows |
| `--text` | `#22301F` | Main text |
| `--text-muted` | `#6B6A5E` | Secondary text, *to confirm* |
| `--line` | `#E4DCCD` | Borders and dividers, *to confirm* |
| `--primary` | `#2F4A3A` | Deep sage: buttons, links, the logo |
| `--accent` | `#C8643B` | Terracotta: badges and the "ready" state only |

## Type

| Role | Family | Size / line height |
| --- | --- | --- |
| Display | Fraunces | 32 / 38, 24 / 30 |
| Body | Inter | 16 / 24, 14 / 20 |

## Spacing and shape

- Spacing base: 4px.
- Radius: 6px (inputs), 12px (cards), full (badges).

## Rules

- Components use tokens only; no raw hex in components.
- Separation by borders, no shadows, like paper.
- Photos always on warm backgrounds, never on white.
- Counter board: touch targets of at least 48px.
