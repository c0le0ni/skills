# Glossary

The game's words, so that everyone means the same thing.

| Term | Meaning |
| --- | --- |
| Board | The grid of grey cells where the game happens |
| Pixel | The green cell the player follows; also what a run earns (px) |
| Catch | Reaching the green pixel before it moves on |
| Streak | Catches in a row in one run; the big number on the left |
| Multiplier | How much each catch is worth, rising with the streak (×1.0, ×6.0) |
| Run | One go, from the first catch until the player "tires" |
| Energy | What runs out and ends a run (to confirm, blocker 1) |
| Upgrade | Something bought with pixels between runs |
| HUD | The numbers left and right of the board |
| Hint | The one line under the board that says what to do |
| Feito por Coleoni | The only credit on the page, linking to coleoni.com |
| Daily challenge | Later: one run a day, the same for everyone, with a ranking |
